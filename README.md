# MV Construction & Builders

A responsive business website developed for MV Construction & Builders to showcase construction services, projects, company information, and customer contact options.

## Live Website

https://mv-construction-builders.vercel.app/

## Features

- Responsive business website
- Home section
- About section
- Services section
- Project showcase
- Contact section
- Direct phone contact
- WhatsApp integration
- Email contact
- Responsive navigation

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS

## Website Sections

### Home

Introduces the construction company with a professional hero section and contact actions.

### About

Provides information about the company and its construction services.

### Services

Showcases the construction services offered by the company.

### Projects

Displays selected construction projects through project cards and images.

### Contact

Provides multiple ways for customers to contact the company, including phone, email, and WhatsApp.

## How to Run

### Clone the repository

```bash
git clone https://github.com/malinih721-spec/mv-construction-builders.git
cd mv-construction-builders/construction-website
````

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

### Build for production

```bash
npm run build
```
